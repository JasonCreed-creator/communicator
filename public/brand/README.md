# 브랜드 자산

디자인지시서 v1 §7 (`docs/mice-communicator-디자인지시서-v1.md`) 기준.

- `remember-logo-offwhite.png` — 사이드바·다크 바 등 다크 컨텍스트 전용
- `remember-logo-black.png` — 라이트 컨텍스트·인쇄 전용
- 높이 20~24px로만 스케일한다. 비율 왜곡·재염색 금지.
- 두 자산 모두 `BrandLogo` 컴포넌트(variant='offwhite'|'black')를 통해서만 사용하며,
  이미지 로드 실패 시에만 텍스트 워드마크로 폴백한다.

## 직인 (견적서 전용 — 2026-09-10 자리 마련 · 2026-09-24 반영)

- `remember-seal.png` — **국문** 견적서(Excel·구글 시트) 공급자 행의 **"(인)" 칸 위에 자동 삽입**된다(`exportEstimate.ts`).
  2026-09-24 사용자 제공 직인을 누끼(배경 제거)해 넣었다: **571×571px 정사각 · 투명 PNG · 잉크 #FF0000(원본 색)**.
  교체할 때는 같은 경로에 같은 규격으로 덮어쓰면 다음 내보내기부터 반영된다(코드 수정 불요).
- 규격: **정사각형 PNG, 투명 배경**, 300×300px 이상 — 여백 없이 도장 외곽선까지 꽉 차게 자를 것.
  JPG·흰 배경은 "(인)" 글자와 행 선을 가리므로 쓰지 않는다(`sealAsset.test.ts`가 서명·정사각·알파를 검사).
- 렌더 크기 **72px**(2026-09-24 사용자 선택 — 60·72·84 실렌더 비교). 공급자 행 중심에 2.5행 걸침,
  A4 한 장 맞춤 인쇄 시 지름 약 12mm.
- **영문 견적서에는 직인도 "(Seal)" 표식도 없다**(2026-09-24 사용자 결정) — 영문 주소가 길어 직인 테두리가 주소 끝 글자를
  덮었다(60px도 동일). 영문 공급자 행은 다른 행처럼 G:H 병합이고, 직인 파일을 받지도 않는다(주입 `sealBase64`도 동일).
- **리멤버 브랜드 견적서에만** 쓴다 — 다른 공급자 명의(화이트라벨) 견적서는 자기 `sealBase64`가 있을 때만 직인.
- **공개 노출(사용자 결정 2026-09-24)**: `public/`은 누구나 받는 경로다 — `/brand/remember-seal.png`로 직인 PNG를 받을 수
  있고, 로그인 없는 mock 운영 중에는 방문자 누구나 직인 찍힌 견적서를 만들 수 있다. 대안(브라우저별 등록)을 비교한 뒤
  공개 경로를 택했다. 로그인 전환(Phase 4) 뒤 비공개 보관으로 옮길지 다시 판단한다.
- 데모 아티팩트에는 **싣지 않는다**(`demo/plugins.ts` — 링크 공유 페이지이고 내려받기가 막혀 쓰일 곳이 없다).
- 파일이 없으면 호스트가 index.html을 200으로 돌려준다(SPA rewrite) — `loadAssetBase64`가 PNG 서명으로 걸러
  직인 없이 "(인)" 글자만 나간다. `npm run deploy:check`가 이 경로가 실제 PNG로 서빙되는지 검사한다.
- 검증: `src/modules/quote/__tests__/sealAsset.test.ts`(자산 계약·H7 중심 72px·영문 미삽입·SPA 폴백·화이트라벨) ·
  `exportEstimate.test.ts` "리멤버 기본 레이아웃 직인" · `demo:smoke` ③-2(데모 Excel = 로고 1장, 직인 0).
