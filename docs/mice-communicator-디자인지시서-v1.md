## 4. 레이아웃 전면 전환 — 구분감의 근본 해결

- **내부 화면: 상단 탭 → 좌측 사이드바(고정 232px, --dark 배경)**. 상단에 offwhite 로고, 메뉴는 아이콘+라벨(--dark-ink 70%), 활성 항목 = 오렌지 3px 좌측 마커 + 텍스트 100%. 하단에 행사명·유형 뱃지·설정. 모바일(<768px)은 햄버거 드로어.
- 콘텐츠 영역: --canvas 배경, max-width 1120 중앙, 페이지 헤더 패턴 통일(캡션 라벨 → 타이틀 25 → 우측 액션 버튼).
- **발주처 뷰: 사이드바 없음.** 슬림 다크 상단 바(--dark + offwhite 로고 + 행사명), 이하 모바일 1열 카드.

## 5. 컴포넌트 규격

- 카드: --card + 1px --border + r12 + 그림자 1단계. 카드 안 카드 금지(면 분리는 --canvas 인셋으로).
- 버튼: primary(--ink bg/white) · accent(--accent bg/white — 컨펌 발송·승인 등 핵심 CTA 전용, 화면당 1개 원칙) · ghost(1px --border). 높이 36, r6.
- 테이블: 헤더 = 캡션 스타일(--ink-cap, 12/500) + 하단 1px --border-strong, 행 높이 44, hover --accent-tint 30%, 줄무늬 금지.
- 입력: --card bg + --border, focus 시 --accent 1.5px 링. 라벨은 캡션 스타일. **상세 규격은 §5-1 입력 폼 정본.**
- 진행바: 트랙 --track, 필 --accent, 높이 6, r3. 수치 라벨은 항상 바 **아래** 줄(겹침 재발 금지).
- 빈 상태: 중앙 아이콘(--ink-cap) + 한 줄 설명 + ghost CTA.

> 임의 사용 금지"를 네이티브 컨트롤 쪽에서 우회했고, 숫자·날짜·셀렉트 62개는 정렬·자릿 구분·화살표가
> 화면마다 달랐다. 실장 위치는 `src/index.css`(CSS)와 `src/components/internal/`(컴포넌트)이다.

### 5-1.1 컨트롤 6종 — 높이 36 · r6 · 포커스 accent 1.5px (`.ui-input` 확장)

| 종류 | 클래스 | 규격 |
| --- | --- | --- |
| 텍스트 | `.ui-input` | 기본 — 그대로 |
| 수량·정원 | `.ui-input ui-input-num` | 우측정렬 · tabular-nums · **스피너 제거** |
| 금액 | `MoneyField` | 천단위 구분 + 아래 줄 한글 에코(`1,200만원`, --accent-deep) |
| 날짜·시간 | `.ui-input` | **네이티브 유지** · 표기 `YYYY-MM-DD` 고정 (`ui-input-num` 금지) |
| 셀렉트 | `.ui-input ui-select` | OS 화살표 제거 → ink-cap 셰브론 자체 렌더 · 우측 여백 32 |
| 긴 텍스트 | `.ui-input` + `rows={3}` | 3줄 고정 · 자동 확장 없음 |

`accent-color: var(--accent)`는 `@layer base`에 **1회만** 선언한다 — 이 한 줄이 컨트롤 전부를 정본에
넣는다. 화면이 인라인으로 되칠하지 않는다(상시 가드).

### 5-1.2 체크 · 라디오

- 크기 **16(내부) · 20(외부 지면)** — `.ui-check` / `.ui-check ui-check-lg`
- 클릭 영역은 컨트롤이 아니라 **라벨 행 전체** — 감싸는 라벨에 `.ui-check-row`(min-height 36)
- `/c`·`/p`·현장 체크인은 `.ui-check-row-touch`로 **행 높이 44 고정** — §7-1.7 터치 규정은 버튼만의 규정이 아니다

### 5-1.3 선택 카드 — 표시는 두 겹까지

선택 표시는 **`border-accent` + `bg-accent-tint`**까지다. `선택` 필(pill)을 얹지 않는다 — 라디오·보더·
틴트가 이미 세 번 말한다. 우측 배지 자리는 `가정`처럼 **정보를 더하는 배지 전용**이다(accent 필과
나란히 서면 둘 다 안 읽힌다).

### 5-1.4 필드 상태 5종 (`Field` — `src/components/internal/Field.tsx`)

기본(힌트 한 줄) · 포커스(accent 1.5px 링) · 오류(`.ui-input-error`) · 비활성(`.ui-input:disabled` —
track 면 + ink-cap) · 읽기 전용(`.ui-input-readonly` — 면·보더 없이 값만 600).

- **오류는 힌트 줄을 대체한다. 두 줄로 쌓지 않는다** — 필드 높이가 폼마다 달라진다.
- 필드 단위 오류가 있으면 `ErrorAlert` 블록을 겹쳐 띄우지 않는다. **블록 경고는 저장 실패(서버·권한) 전용.**
- 필수는 라벨 뒤 `*` 하나(--accent-deep). `required` 배지·빨간 라벨은 쓰지 않는다.

### 5-1.5 폼 안 버튼 위계 — 화면당 주 버튼 1개

- 행·카드 단위 저장은 `btn btn-ghost btn-sm`, 라벨은 **`저장`** — 카드 제목을 버튼이 다시 읽지 않는다.
- 변경 전에는 **비활성**, 저장 후에는 버튼 옆 `저장됨 hh:mm` 캡션. 성공 배지·토스트는 쓰지 않는다.
- `btn-accent`는 외부 지면 승인 CTA 전용 — **내부 폼 저장에 쓰지 않는다.** 위저드의 전진 버튼만 주 버튼이다.

### 5-1.6 인쇄

`.ui-select`는 셰브론과 우측 여백을 되돌리고, `.ui-input`·`.ui-input-readonly`는 배경을 비우고 보더만
남긴다 — 종이에서 누를 수 없는 컨트롤이 잉크를 먹지 않게 한다.

## 7-1. 공통 패턴 정본 (v1.1 — 디자인 핸드오프 `패턴 기준 시트` 2026-08-28 사용자 승인)

> v1이 "미정의"로 남긴 **표·빈 상태·차트·인쇄 규격**을 정본화하고, 5계열로 흩어져 있던 **상태 배지를 의미 4단계로 통합**한다.
> 본 절과 §3이 충돌하면 **본 절이 우선**한다. 구현체는 `src/index.css`(표·인쇄) · `src/lib/labels.ts`(레벨 매핑) ·
> `src/components/internal/*`(프리미티브)이며, 화면은 이들을 **재구현하지 말고 사용**한다.

### 7-1.1 상태 배지 — 의미 4단계 + 중립

색은 **의미**만 나타낸다. 계열(컨펌·WBS·파트너·정산·시트)은 색이 아니라 **배지 앞 접두 라벨**로 구분한다.

| 단계 | 배경 / 텍스트 | 뜻 |
| --- | --- | --- |
| 중립 `neutral` | `track` / `ink-sub` | 아직 시작 안 함 — 초안·미배정·미연결 |
| 진행 `progress` | `steel-tint` / `steel` | 움직이는 중, 개입 불필요 |
| 주의 `attention` | `accent-tint` / `accent-deep` | **내 행동을 기다림** |
| 정상 `positive` | `positive-tint` / `positive` | 끝남 — 승인·확정·완료 |
| 차단 `blocked` | `negative-tint` / `negative` | 막힘·지연 — 수정요청·초과·실패 |

5계열 매핑(중립 / 진행 / 주의 / 정상 / 차단):

| 계열 | 중립 | 진행 | 주의 | 정상 | 차단 |
| --- | --- | --- | --- | --- | --- |
| 컨펌 | 초안 | 내부검토 | 컨펌대기 ● | 승인·확정 | 수정요청 |
| WBS | 미착수 | 진행 | 마감 임박 | 완료 | 지연 |
| 파트너 | 미배정 | 참여 중 | 제출 임박 | 제출 완료 | 철회 |
| 정산 | 미정산 | 정산 중 | 확인 필요 | 정산 완료 | 예산 초과 |
| 시트 | 미연결 | 동기화 중 | 갱신 있음 ● | 연결됨 | 권한 끊김 |

**규칙** — 좌측 6px 도트는 **'내 행동을 기다리는' 상태 하나에만**(컨펌 `pending_approval`, 시트 '갱신 있음').
주의 단계 전부에 붙이면 신호가 죽는다. 한 화면에 한 계열만 나오는 표에서는 접두 라벨을 생략한다(열 헤더가 이미 계열을 말한다).
색만으로 구분하지 않으며 배지는 언제나 라벨 텍스트를 동반한다. 카드 좌측 3px 상태 스트립은 배지의 원색 계열 그대로, 중립만 `border-strong`.

**인쇄 변형** — tint 배경 제거 → 1px 보더 + 잉크 텍스트 + 선행 글리프(`○ 초안` / `◐ 내부검토` / `● 컨펌대기` / `✓ 승인` / `▲ 수정요청`).
주의·차단만 1.5px, 차단은 점선.

### 7-1.2 역할 표시 — 형태로만

상태 = **면**(tint 배경 pill). 역할 = **형태**(좌측 4px 바 · 8px 도트 · 간트 바). **역할에 pill 배지를 쓰지 않는다.**
표에서 역할 바는 스티키 첫 열 **바깥 최외곽**에 두거나 담당자 이름 앞 도트로 — 스티키 열과 겹치면 가로 스크롤 시 잘린다.
