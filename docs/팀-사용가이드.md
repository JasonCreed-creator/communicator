## 📌 한눈에 보기

- **로그인**: **시험용 입구**에서 내 이름 카드를 누릅니다. 입구는 2026-10-05(월) 18:00까지 열려 있고, 로그인 방식이 바뀌면 다시 알립니다.
- **매일 여는 곳**: **홈**의 **오늘 할 일**. 지연된 일, 컨펌 대기, 미등록 파일이 급한 순서로 한 목록에 모입니다.
- **알림**: 행사마다 Slack 스레드(운영·디자인)로 옵니다. 할 일이 생긴 사람만 @멘션합니다.
- **파일**: 올리면 Google Drive 행사 폴더에 들어가고, 파일 이름은 앱이 붙입니다.
- **발주처**: 로그인 없이 발주처 전용 링크로 들어와 승인하거나 수정요청을 남깁니다.

### 지금 알아둘 것

1. **발주처에게 이메일이 자동으로 가지 않습니다.** 컨펌을 보낸 뒤 발주처 링크를 복사해 직접 전달하세요. 내부 Slack 알림은 자동으로 갑니다.

- **발주처 화면의 제출 자료 접수**: 준비 중입니다. 발주처 자료는 메일로 받아 행사 폴더에 올리세요.
- **외화 견적 환산**: 원화로 바꾸지 않고 경고만 띄웁니다.

## 🧭 행사 한 건의 흐름

| 단계 | 누가 | 어디서 | 끝나면 |
|---|---|---|---|
| 1 행사 만들기 | PM | 행사 목록 → ＋ 새 행사 만들기 | 행사 ID · WBS · R&R 카드가 자동으로 생김 |
| 2 연동 | PM | 행사 설정 → 유형·연동 | Slack 스레드 연결 · Drive 행사 폴더 |
| 3 발주처 링크 | PM | 행사 설정 → 담당자 → 발주처 연락처·토큰 | 발주처 전용 링크 |
| 4 견적 연결 | 영업 · PM | 견적 → 견적서 가져오기 | 정산보드 기준 견적 |
| 5 제작·컨펌 | 담당자 → PM → 발주처 | 디자인 보드(운영 보드의 파일 항목 포함) → 항목 상세 | 확정본 사본이 Drive 납품 폴더에 |
| 6 운영 문서 | 운영 | 운영 보드 → 운영계획서 | A4 · 16:9 장표 PDF |
| 7 등록·현장 | 등록 | 등록 → 현장 체크인 | 명단 · 체크인 현황 |
| 8 정산 | PM | 정산보드 | 최종 마진 |

### 제작물 상태 7단계

| 상태 | 뜻 | 다음에 할 사람 |
|---|---|---|
| 가이드됨 | PM이 제작 가이드를 발행함 | 담당자 · 첫 시안 올리기 |
| 초안 | 작업 중(첫 파일을 올리면 이 상태) | 담당자 · 내부검토 요청 |
| 내부검토 | PM 검토를 기다림 | PM · 반려하거나 컨펌 발송 |
| 컨펌대기 | 발주처에 보냄 | 발주처 · 승인하거나 수정요청 |
| 수정요청 | 발주처가 고쳐 달라고 함 | 담당자 · 수정본 올리기 |
| 승인 | 발주처가 승인함 | 자동 · 확정본 정리 |
| 확정 | 끝. 확정본 사본이 Drive 납품 폴더에 저장됨 | 없음 |

- PM이 **반려**하면 초안으로 돌아갑니다. 반려 사유는 꼭 적어야 합니다.
- 수정본을 올리면 초안으로 돌아가고, 다시 내부검토 요청부터 이어집니다.
- **컨펌대기 · 승인 · 확정** 상태에서는 새 버전을 올릴 수 없습니다. 확정된 항목을 바꿔야 하면 새 항목을 만드세요.
- 주최형 행사의 파트너 항목은 상태 이름이 조금 다릅니다(제출 요청됨 · 검토중 · 승인됨).

## 🙋 역할별 빠른 시작

### PM

1. **행사 목록 → ＋ 새 행사 만들기**를 누르면 3단계 설정이 열립니다. 단계마다 저장되니 **나중에 하기**로 나갔다가, **행사 목록 → 먼저 확인할 행사 → 이어서 세팅하기**로 돌아와 계속하면 됩니다.
2. **① 행사 기본 정보**: 필수 4칸(행사명 · 고객사 · 행사일 · 장소)을 채웁니다. Slack 요청 글이 있으면 **Slack 메시지에서 불러오기**에 메시지 링크나 글을 붙이고 **불러오기**를 누르세요. 채운 칸은 주황색으로 표시되니 원문과 대조한 뒤 저장합니다. 견적서 파일이나 링크도 여기서 첨부할 수 있습니다.
3. **② 담당자 배정**: 주소록 카드를 눌러 역할을 고르거나, 카드를 역할 칸(PM · 디자인 · 운영 · 등록)으로 끌어다 놓습니다. 발주처 연락처도 여기서 추가할 수 있습니다(선택).
4. **③ 유형 고르고 확인**: 행사 포맷(컨퍼런스 일반형 · 컨퍼런스 모객형 · DMS · 전시회)을 고르고 **온보딩 완료**를 누릅니다. 행사일을 기준으로 WBS와 역할별 R&R 카드가 자동으로 생깁니다.
5. **Slack 연결**: 먼저 운영 채널에 이 행사의 스레드를 엽니다(첫 글에 행사 ID를 적으면 찾기 쉽습니다). 그 첫 글에서 **링크 복사**를 누르고, 앱의 **행사 설정 → 유형·연동 → Slack 알림**에서 **행사 스레드 (운영 채널)** 칸에 붙인 뒤 **스레드 등록 → 테스트 보내기**를 누릅니다. 디자인 채널을 따로 쓰면 같은 방법으로 **디자인 스레드**도 등록하세요. 봇(앱)이 그 채널에 들어가 있어야 합니다.
6. **발주처 링크**: **행사 설정 → 담당자 → 발주처 연락처·토큰**에서 **연락처 추가 → 발급 → 링크 복사**를 누릅니다. 링크는 기본으로 행사일 30일 뒤에 만료되고, **회수**하면 바로 막힙니다. 다시 보내려면 새로 발급하세요.
7. **제작 지시**: 디자인 보드나 운영 보드에서 **＋ 항목 추가**를 누르고 **제작 가이드 포함**을 체크합니다. 담당·마감·가이드 내용·규격을 적고 **가이드 발행**을 누르면 담당자에게 Slack 제작 요청 카드가 갑니다.
8. **검토와 발송**: 담당자가 내부검토를 요청하면 항목 상세의 **다음 단계**에서 처리합니다. 고칠 게 있으면 **반려**(사유 필수), 괜찮으면 **답 기한**을 정하고 **컨펌 발송**을 누릅니다. 그다음 발주처 링크를 발주처에 전달하세요.
9. 매일 **홈 → 오늘 할 일**을 봅니다. 밀린 일은 **담당에게 리마인드**, 발주처 답이 늦으면 **컨펌 독촉**으로 스레드에 알립니다. 같은 대상에게는 한 시간에 한 번 보낼 수 있습니다.

### 디자인

1. Slack 행사 스레드(디자인 스레드를 따로 쓰면 그 스레드)에 **[의뢰]** 카드가 오면 **확인했어요**를 누르고, **앱에서 열기**로 항목에 들어갑니다.
2. 항목 상세 **다음 단계**에서 **첫 시안 올리기**를 누릅니다. 파일을 끌어다 놓거나, **파일 선택**·**폴더 선택**을 쓰거나, **Drive 링크로 등록**할 수 있습니다.
3. 작업이 끝나면 **내부검토 요청**을 누릅니다. PM이 확인한 뒤 발주처로 보냅니다.
4. **[피드백]**(발주처 수정요청)이 오면 발주처 코멘트를 보고 **수정본 올리기** → **내부검토 요청** 순서로 다시 진행합니다.

- **디자인 보드**의 **우리 차례** 칩을 누르면 지금 우리가 할 일만 보입니다. 늦은 항목만 보려면 **지연만**을 누릅니다.
- 발주처에 보낼 버전은 **PDF·PNG·JPG** 파일이어야 합니다. 원본 파일(AI·PSD 등)을 올렸다면 확인용 PDF나 JPG도 새 버전으로 올려 두세요.
- 코멘트는 기본이 **내부 메모**입니다. 발주처에게 보여야 하는 말만 **발주처와 공유**로 바꿔서 남기세요.

### 운영

1. **프로그램표부터** 채웁니다. **운영계획서 → 02 프로그램**에서 세션·시간·연사를 넣습니다(PM·운영). 시나리오 뼈대와 운영가이드 진행표가 여기서 만들어집니다.
2. **운영 보드**에는 카드 4개(**큐시트 · 시나리오 · 운영가이드 · 기타 제작물**)가 있습니다. **＋ 항목 추가**로 문서를 만들고, 목록에서 **열기**를 누르면 그 자리에서 편집됩니다.
3. **큐시트**: **큐 추가**로 줄을 만들고, 줄을 끌어서 순서를 바꿉니다. 줄 끝 **⋯**에서 고치기·대본 편집·옮기기·지우기를 합니다. 칸은 시각 · 큐 · 구분 · MC · 진행 · 조명 · 영상 · 음향입니다.
4. **시나리오**: 빈 문서에서 **프로그램표에서 뼈대 만들기**를 누른 뒤 **＋ 멘트** · **＋ 지시** · **＋ 비상 멘트**로 원고를 채웁니다. 연사 이름이 비어 있으면 **연사 확인 대기**가 뜹니다. 완성되면 **큐시트로 보내기**로 큐시트에 옮깁니다.
5. **운영가이드**: **기본 섹션 만들기**를 누르면 섹션 12개(설치·철거 일정 · 현장 인력·콜타임 · 무전·지휘 체계 · 역할 분담 · D-day 진행표 · 구간별 체크리스트 · 등록 운영 · VIP 의전 · 안전관리 · 존별 운영 · 비상 대응 · 연락망/비품)가 생깁니다. 표를 채우면 됩니다. 개인 휴대폰 번호는 적지 않습니다.
6. **운영계획서**에는 위 내용이 자동으로 모입니다. **인쇄 · PDF**로 A4 문서를 저장하거나, **16:9 장표 → 인쇄 · PDF**로 발표용 PDF를 만듭니다.

- **발주처에게 운영 문서를 보낼 때**는 PDF로 저장해 직접 전달합니다. 시나리오는 **인쇄 · MC 배포용**, 운영가이드는 **인쇄 · 스태프 배포용**, 큐시트는 운영계획서의 **인쇄 · PDF**를 씁니다. 앱의 컨펌 발송으로 보내면 발주처 화면에 문서 내용이 열리지 않습니다.

### 등록

1. **등록 → 참관객** 탭(모객형 행사는 **RSVP** 탭도)에서 **CSV 임포트**를 누르고 명단 파일(.csv·.xlsx)을 고릅니다.
2. 파일의 머리글을 앱의 칸(이름·이메일 등)에 맞추고 **가져오기 실행**을 누릅니다. 이메일이 같은 사람은 새로 만들지 않고 갱신합니다.
3. **통계** 탭에서 등록 현황을 봅니다.
4. 행사 당일에는 **현장 체크인**을 엽니다. 이름·소속·뱃지번호로 찾고 **체크인**을 누릅니다. 잘못 눌렀으면 **체크인 취소**를 누르세요.

- 연락처(이메일·전화)는 기본으로 일부가 가려져 보입니다.
- 현장 체크인 화면에는 명단 편집·시트 설정·내보내기가 없습니다. 당일 접수에만 씁니다.

### 영업 · 관리자

1. **견적 → ＋ 새 견적**: 5단계(규모·유형 · 베뉴 · 옵션 · 확인·확정 · 행사 만들기)로 작성합니다. **확인·확정**에서 저장한 뒤 **이 버전으로 확정**을 누릅니다. 확정한 견적은 잠기고, 고치면 새 버전이 생깁니다.
2. 견적서 파일이 필요하면 견적 목록에서 견적을 고르고 **Excel 내려받기** 또는 **구글 시트로 만들기**를 누릅니다. 구글 시트는 Drive 저장소의 `00_견적서` 폴더에 만들어집니다.
3. 받은 견적서 파일이 있으면 **견적서 가져오기**를 씁니다. ① 파일을 올리고 **인식 시작**(엑셀) 또는 **AI로 읽기**(PDF·사진)를 누릅니다. ② 인식 결과를 확인합니다. ③ **기존 행사에 연결**을 고르고 **정산보드 기준 견적**을 체크합니다.
4. 이미 있는 견적을 행사에 붙이려면 견적 목록에서 견적을 고르고 오른쪽 **기존 행사에 연결**을 누릅니다. 확정 견적으로 행사를 새로 만들려면 **이 견적으로 행사 만들기**를 누릅니다.
5. 온보딩 때 견적서를 첨부했다면 **견적서 가져오기** ①의 **이 파일로 읽기**로 그 파일을 바로 읽을 수 있습니다.

- 관리자만 할 수 있는 일: **Drive 연결**(행사 설정 → 유형·연동), **행사 삭제**(행사 목록 카드의 **⋯ → 삭제…**, 행사 이름을 똑같이 입력해야 지워짐).

### 확인했어요 버튼

- 승인·반려 같은 작업 버튼은 Slack에 없습니다. **앱에서 열기**로 들어가 처리하세요.
- 디자인 스레드를 따로 쓰는 행사에서 디자인 제작 요청을 확인하면, 운영 스레드에 **[키비주얼] 일정 합의** 한 줄이 남습니다.

### 리마인드

### 멘션이 안 올 때

- 봇은 **담당자**(주소록)에 적힌 이메일로 Slack 계정을 찾아 멘션합니다. 못 찾으면 `이름(Slack 미연결)`으로 나옵니다. PM에게 **담당자** 화면에서 이메일을 Slack 계정 이메일과 같게 고치거나 Slack ID를 넣어 달라고 요청하세요.
- 봇이 그 채널에 없으면 글이 가지 않습니다. 비공개 채널은 **채널 세부정보 → 에이전트 및 앱 → 앱 추가**로 봇을 먼저 넣으세요.

## 📁 Drive 폴더와 파일 이름

- 파일은 연결된 Google Drive 저장소에 모입니다. 행사 폴더는 앱이 만들고, 폴더 이름은 **행사 ID**입니다.
- **행사 ID**는 `YYMMDD_고객사_행사명` 형식입니다(예: `261020_가상고객_가상 컨퍼런스`). 행사일·고객사·행사명으로 자동으로 만들어지고, 파일 이름 앞에도 붙습니다. Slack 스레드 첫 글에도 이 ID를 쓰면 찾기 쉽습니다.
- **파일 이름**도 앱이 붙입니다: `행사ID_제목_v1.pdf`. 새 버전을 올리면 v2, v3으로 올라갑니다.

| 폴더 | 들어가는 것 |
|---|---|
| 저장소 / 연도 / 행사 ID | 행사 폴더(행사일의 연도 · 행사일이 없으면 `연도 미정`) |
| 01_견적 | 행사에 첨부한 견적서 |
| 02_계약 | 계약 관련 공통 항목 |
| 03_제작·키비주얼 | 디자인 항목(항목마다 폴더 하나) · KV·초청장·현장물 폴더(직접 정리용) |
| 03_제작·키비주얼 / 납품 | 발주처가 승인한 확정본 사본(자동) |
| 04_WBS·운영계획 | 운영 항목(큐시트·시나리오·운영가이드 등) · 회의록·기획 |
| 05_현장 | 현장 자료(직접 올림) |
| 06_결과보고·정산 | 정산·결과보고 · 협력사 견적서 원본 |
| 99_archive | 지운 항목의 폴더(파일은 지우지 않고 옮김) |

### 파일을 올리는 방법

- **끌어다 놓기**: 항목 상세의 올리기 칸에 파일이나 폴더를 끌어다 놓습니다.
- **파일 선택 · 폴더 선택**: 여러 파일을 고르면 파일마다 버전이 하나씩 생깁니다.
- **Drive 링크로 등록**: 저장소 폴더 안에 있는 파일만 됩니다. 이 행사 폴더 안의 파일은 그대로 연결되고, 저장소의 다른 곳에 있는 파일은 항목 폴더로 복사됩니다. 저장소 밖(개인 드라이브 등) 파일은 먼저 행사 폴더로 옮기세요.
- Drive에 직접 넣은 파일은 **홈 → 오늘 할 일**에 **미등록 파일**로 뜹니다. **항목에 연결**하거나 **무시**를 누르세요. 바로 확인하려면 **Drive 지금 확인**을 누릅니다.
- 앱이 올린 파일을 Drive에서 지우지 마세요. 앱의 버전 링크가 끊깁니다. 필요 없는 항목은 PM이 항목 상세의 **⋯ → 지우기**로 정리합니다. 앱에서는 항목·버전·코멘트가 모두 지워지고(되돌릴 수 없음), Drive의 항목 폴더는 99_archive로 옮겨집니다.

## 🤖 AI 읽기

| 어디서 | 무엇을 읽나 | 누르는 버튼 |
|---|---|---|
| 견적 → 견적서 가져오기 | 견적서 PDF·사진(국문·영문) | AI로 읽기 |
| 정산보드 → 협력사 견적서 불러오기 | 협력사 견적서 PDF·사진 | AI로 읽기 |
| 새 행사 ① → Slack 메시지에서 불러오기 | Slack 요청 글 | 불러오기(규칙으로 먼저 읽고, 못 채운 칸만 AI가 채움) |

- **한도**: 한 사람당 하루 30회이고, 세 곳을 합쳐서 셉니다. 한국 시각 0시에 다시 채워집니다. 엑셀 견적서는 한도 없이 불러올 수 있습니다.
- **파일 크기**: PDF·사진은 3MB까지 읽습니다. 스캔 PDF가 크면 해상도를 낮추거나 쪽을 나눠 올리세요.
- **꼭 사람이 확인합니다**: AI는 보이는 글자를 옮겨 적기만 하고, 합계 검산은 앱이 따로 합니다. **AI가 읽음** 표시가 붙은 결과는 원본과 한 줄씩 대조한 뒤 확정하세요. 확정하기 전에는 견적이나 발주 항목이 만들어지지 않습니다.

## ❓ 자주 막히는 곳

### 새 버전을 올리는 버튼이 없어요

컨펌대기·승인·확정 상태에서는 올릴 수 없습니다. 항목 상세의 **다음 단계** 카드에 이유가 나옵니다. 발주처가 수정요청을 하면 다시 올릴 수 있습니다.

### "PM 전용 기능입니다."가 떠요

그 작업은 이 행사의 PM만 할 수 있습니다. PM에게 요청하거나 역할 배정을 받으세요.

### "이 영역에는 쓰기 권한이 없습니다(열람만 가능)."가 떠요

다른 영역의 보드입니다. 그 영역 역할이 있어야 항목을 만들고 파일을 올릴 수 있습니다.

### 컨펌 발송이 안 돼요

보낼 버전이 PDF·PNG·JPG여야 합니다. 확인용 파일을 새 버전으로 올린 뒤 다시 보내세요.

### 발주처가 "링크가 만료되었습니다"라고 해요

링크가 회수됐거나 기한이 지났습니다. PM이 **행사 설정 → 담당자 → 발주처 연락처·토큰**에서 새로 발급해 다시 보냅니다.

### Slack 멘션이 안 와요

알림에 `이름(Slack 미연결)`으로 보이면 주소록 이메일이 Slack 계정 이메일과 다른 경우입니다. PM에게 **담당자**에서 고쳐 달라고 요청하세요.

### Drive 링크 등록이 거부돼요

저장소 폴더 밖의 파일입니다. 먼저 행사 폴더로 옮긴 뒤 링크를 붙이세요.

### 행사가 목록에 안 보여요

그 행사의 담당자로 배정되지 않았습니다. 그 행사 PM에게 배정을 요청하세요.

### "오늘 AI 읽기를 모두 썼습니다"가 떠요

하루 한도를 다 쓴 것입니다. 한국 시각 0시에 다시 쓸 수 있고, 엑셀 견적서는 지금도 불러올 수 있습니다.

### 행사일이 바뀌었는데 일정이 그대로예요

**일정** 화면에 "행사일이 변경되었습니다" 안내가 뜹니다. PM이 **템플릿 재전개**를 누르면 WBS 날짜가 새 행사일로 다시 맞춰집니다.

### 담당자를 주소록에서 지울 수 없어요

배정된 행사가 있으면 지울 수 없습니다. 각 행사의 담당자에서 먼저 빼세요.
